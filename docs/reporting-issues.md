# Reporting Issues

If you encounter any issues when using or developing Torizon OS, you can open a
new issue in the relevant repository's issue tracker:

- Distro (image composition, OTA, containers, OS policy):
  <https://github.com/torizon/meta-torizon/issues>
- BSP (machine bring-up, bootloader/kernel, per-vendor adaptation):
  <https://github.com/torizon/meta-torizon-bsp/issues>

If you are unsure which layer is responsible, or would prefer general help, you
can also create a new Technical Support topic in the
[Toradex Developer Community](https://community.toradex.com/).
